인정학원 인적정보 시스템 — 공개 배포용

사용법
1. 압축을 풀고 폴더 구조를 유지하세요.
2. GitHub Pages 또는 Cloudflare Pages 등 HTTPS 호스팅에 폴더 안의 모든 파일을 업로드하세요.
3. index.html이 사이트 최상위 경로에 있어야 합니다.
4. 홈 화면에 추가해서 PWA처럼 실행할 수 있습니다.

열람 방식
- 방문자: 기본 공개 기록 열람
- 자료 열람 인증: 031130 (발현/입소 이력 등)
- 관계자 로그인: 견/SBSB, 묘/GCGC, 유월/GAGA, 콜/SXSX, 능여/SXSX
- 관계자 로그인 후에도 본명은 항상 □□□로 표시됩니다.
- 본명 마스킹 부분을 누르면 별도의 입력 화면이 나타납니다.
- 인증값을 입력하면 ERR-503 화면 안내가 표시되고, 본명 원문은 열리지 않습니다.

공개 HTML/JS/파일 어디에도 본명 원문 또는 본명용 별도 인증값을 포함하지 않았습니다.
주의: 이 버전에는 다른 비공개 인물 서사와 관계자 계정 비밀번호가 HTML/JS에 포함되어 있습니다.
실제로 숨겨야 할 기록이나 계정 인증은 서버에 별도로 저장해야 합니다.
